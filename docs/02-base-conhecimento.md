# NEXA TechHelp — Base de Conhecimento

A base de conhecimento é a fonte de referência do agente para problemas básicos de informática.

## Categorias

1. Windows
2. Hardware
3. Software
4. Arquivos e pastas
5. Internet
6. Segurança digital
7. Google Workspace
8. LibreOffice
9. Manutenção básica
10. Hardware e software

## Estrutura conceitual

Cada conhecimento pode conter:

- categoria;
- problema;
- sintomas;
- perguntas de diagnóstico;
- causas possíveis;
- procedimentos;
- nível de risco;
- encaminhamento.

## Regra

Quando a informação não estiver disponível ou não houver contexto suficiente, o agente deve admitir a limitação em vez de inventar uma resposta.

A versão estruturada dos conhecimentos será mantida em `data/base_conhecimento.json`.
